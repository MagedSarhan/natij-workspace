# NATIJ Workspace

مساحة عمل ناتِج — مشاريع، مهام، فريق، سجل نشاط وإشعارات.

- الموقع: https://workspace.natij.digital (Hostinger، نشر تلقائي من هذا الفرع `workspace`)
- قاعدة البيانات: Supabase project `natij-workspace` (MagedSarhan's Org) — المخطط في `database/schema.sql`
- الإعدادات: `config.js` (رابط Supabase + المفتاح العام فقط)
- المدير العام: البريد المسجل في جدول `app_settings` (`owner_emails`)
